Privacy policy

Hermes backup is a private, single-user backup tool. It is used only by its owner, on his own computer, with his own Google account.

  • It uses the Google Drive API with the drive.file scope, so it can only see and change files it created itself.
  • It uploads the owner's own backup data, encrypted on his computer before upload, to his own Google Drive.
  • It does not collect, share, sell or send any data to anyone else, and it has no servers of its own.
  • Google sign-in tokens are stored only on the owner's computer.

Google API use complies with the Google API Services User Data Policy, including the Limited Use requirements.
